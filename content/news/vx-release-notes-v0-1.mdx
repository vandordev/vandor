`vx v0.1` is the first public release line for the CLI.

## In this release

- initial product landing under `/vx/:version`
- versioned documentation routes with `latest` preserved in the URL
- a stronger foundation for structured Go backend scaffolding

## What we optimized for

This release is less about surface area and more about direction.

We want the first public versions of `vx` to be explicit about:

- where product docs live
- how versions are handled
- how Vandor presents product writing separately from reference docs

## What comes next

Future iterations can add richer product content, more opinionated scaffolding flows, and a clearer bridge from announcement posts into the docs surface.
